# Python scripts
This folder contains Python scripts. All scripts made here are supposed to be run as Python 3+ and above. Each Python minimal version may vary by the feature set being used.

So far it houses 2 scripts at the time of writing. They are:
* **convunix2nt.py** - Converts a given Unix (i.e Linux-like) path into NT (i.e Windows-like) path. Useful if you are using something like Wine where you need to open a file with a dialog box but do not wish to use Wine's file picker.
* **listword.py** - Lists every character in a word with a number next to it. Useful for stuff like security verifications where for some reason you are required to type in characters in specific positions instead of a full password.
